# アルゴリズム解説

本書は完成版 `gpp_utils` の計算仕様をまとめる。実装の正本は [application-plan.md](application-plan.md)、保存形式の正本は [output-format.md](output-format.md) とする。

## 1. 問題と状態

無向・重みなし・自己ループ／多重辺なしのグラフを `G=(V,E)`、`n=|V|`、`m=|E|` とする。分割は `x∈{false,true}^n`、true群のサイズを`t`、false群を`f=n-t`とし、目的関数は

`S(x) = C(x) + alpha * (t-f)^2`

である。`C(x)`は端点の所属が異なる辺数、`alpha`の既定値は0.05。Flipは1頂点を反転し任意の`t`を許す。Swapは異なる群の頂点を1つずつ交換し、偶数`n`と`t=f=n/2`を維持する。

## 2. 差分評価

頂点`v`の次数を`d_v`、現在カットされている接続数を`c_v`とすると、Flipのカット数差分は

`Delta C = d_v - 2*c_v`。

群サイズを更新した`(C',t',f')`から、必ず`C' + alpha*(t'-f')^2`を再構成する。`cuts_at[v]`を保持して隣接頂点だけ増分更新し、候補評価は`O(1)`、適用は`O(d_v)`で行う。Swapは交換する2頂点の周辺辺だけを差分更新する。小規模テストでは全再計算と`f64::to_bits()`まで一致させる。

## 3. グラフ生成

Randomは全頂点対を走査する Erdős–Rényi `G(n,p)` とし、`p=expected_degree/(n-1)`。Geometricは`[0,1]^2`へ一様配置し、距離閾値以内を辺とする。指定次数は生成パラメータであり、実平均次数は保存辺リストから算出する。保存グラフは正規化辺リストと内容ハッシュを正本とし、座標や隣接リストの重複保存は行わない。

## 4. 平滑化

HCとSAだけが平滑化を使用する。`none`は`S(x)`、`all_average`は全距離1近傍の平均、`random_k_average`は距離1を非復元抽出し不足時に距離2を使う、`weighted_average`は

`w * mean_distance1 + (1-w) * S(x)`, `w=min(K,M)/M`

（`M`は距離1近傍数）である。Flipの距離2は異なる2頂点反転、Swapの距離2は各群2頂点交換。`k_average`は存在せず、Kの範囲・重複・正規化は設定検証で決める。ランダム平滑化は探索中に再抽選し、計測時はチェックポイントごとに近傍 ordinal の集合を固定する。

## 5. 探索手法

### Hill Climbing

全近傍から平滑化評価が最小の厳密な改善を選び、改善がなければ終了する。最小候補が同点なら専用RNGで一様に選ぶ。確率的平滑化ではサンプル上の改善なしを `no_sampled_improvement` とする。

### Simulated Annealing

近傍を一様に選び、`Delta = eval(candidate)-eval(current)`として、改善は常に受理、悪化は`exp(-Delta/T)`、`T=0`では拒否する固定温度Metropolis法。棄却候補は現行解・暫定解に含めない。

### Extremal Optimization

頂点`i`の組み込み適応度は

`good_edge_fraction(i) = g_i/(g_i+b_i)`

で、孤立頂点は1。小さい適応度を順位1とし、`P(r) ∝ r^(-tau)`で順位を選び、FlipまたはSwapを常に適用する。Swapの2頂点目は全体順位の重みを反対群へ条件付けし、反対群内で順位を振り直さない。`taus`は有限・正の非空配列で必須。EOに平滑化は指定できない。

適応度は `VertexFitness` trait と `FitnessRegistry` でRustから追加登録できる。配布版の登録は`default`だけで、未知名・バージョン不一致は拒否する。

## 6. 乱数と計測

グラフ生成、初期分割、探索、平滑化、同点処理、計測を用途別RNGへ分離し、SHA-256と固定エンディアンで導出する。探索RNGは計測頻度、診断、並列順序の影響を受けない。各保存計測点で現行解と、そこまでの実評価値最小の暫定解を保持し、同一分割は共有プールへ一度だけ登録する。ベイスン計測の解は探索の暫定解に混ぜず、終点分割は保存しない。

## 7. 計算量

全目的関数評価は`O(n+m)`、差分Flip候補は`O(1)`、移動適用は`O(deg(v))`。HCの距離1全走査は候補数に比例し、SAの`none`は1ステップあたり平均`O(m/n)`、EOは適応度計算と順位抽選のコストを要する。距離2を含む平滑化とベイスン計測は設定上限に応じて増加する。
