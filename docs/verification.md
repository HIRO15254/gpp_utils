## 探索性能

同一Windows環境・release設定、Random 500頂点・期待次数5・グラフシード42、Flip、SA温度1、100万ステップ、平滑化なしで測定した。ウォームアップ1回の後、3回の中央値を比較する。

旧実装は保全したコピーからベイスン計測呼び出しだけを外して探索を測定し、48.35msだった。新実装は`cargo run --release --example bench_search`で初期・終了点だけを保存し、ベイスンなしで測定した。最終ビルドの再測定は32.428、45.093、53.362ms、中央値45.093msで、10%超の性能低下は認めなかった。乱数導出仕様は変更しており、同一探索軌跡の速度比較ではない。
